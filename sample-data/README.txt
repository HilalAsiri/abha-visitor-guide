This folder contains the reviewed local catalog loaded by the static guide.

Each public place keeps bilingual copy, coordinates used by both Leaflet and Google Maps, a local media reference, tags, source IDs, a review date, and a precision status. A venue pin is not the same as an area reference: area-reference cards explicitly ask visitors to confirm their access point.

The Curated Visitor Assistant uses only this local catalog. It sends no visitor selections or text to an AI provider or any backend, and it does not supply live booking, price, traffic, weather, or opening-hour information.
